# Project Exam 1 - Momentum

![Momentum screenshot](Momentum.jpeg)

Momentum is a dynamic workout blog where users can explore posts on strength training, cardio, nutrition, and fitness tips. Built using vanilla JavaScript, HTML, and CSS, it connects to an external API to fetch and manage blog content.

## Description

Momentum is an interactive and responsive workout blog that allows users to browse fitness-related articles, read detailed posts, and—if authorized—create, edit, and delete blog posts.

This project was built as part of my **Project Exam 1**, demonstrating skills in front-end development, API integration, and project methodology.

### **Features**

- **Blog Feed Page:** Displays a **carousel** with the latest posts and a grid of **at least 12 blog posts**.
- **Individual Blog Post Page:** Shows detailed content, including **title, author, date, image, and body text**.
- **Shareable URLs:** Each blog post has a unique **shareable link**.
- **Create Post Page:** The owner can **add new blog posts** (title, body, and image).
- **Edit & Delete Post Page:** The owner can **edit or delete** blog posts.
- **User Authentication:** The owner must **log in** to manage posts.
- **Fully Responsive Design:** Optimized for both desktop and mobile.

## Built With

This project was built using:

- **HTML5**
- **CSS3**
- **JavaScript**
- **Fetch API** (for dynamic blog content)
- **LocalStorage** (for managing user authentication)
